# F.R.E.D. (Fantasy Recognition Evaluation Determinator)

An AI-powered fantasy football analytics and decision support application built w/ Python.

## Project Overview

The application analyzes fantasy football data to help managers make better roster decisions.

Initial development focuses on a 16-team ESPN fantasy football league using half-PPR scoring.

## Planned Features

- ESPN league data collection
- Player statistics and projections
- Player valuation and positional scarcity
- Fantasy roster analysis
- Trade evaluation
- Waiver wire recommendations
- Weekly lineup optimization
- ChatGPT and Claude integration
- Interactive analytics dashboard

## Technology Stack

- Python
- pandas
- NumPy
- SQLite
- Streamlit
- OpenAPI AI
- Anthropic AI
